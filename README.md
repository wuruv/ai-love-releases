# AI LOVE — AI texting assistant for Telegram

**[ailoveapp.site](https://ailoveapp.site)** · [Русский](https://ailoveapp.site/ru)

AI LOVE is an app for **Windows** and **Android** with an AI that keeps the Telegram chats you choose going in your name — short, human replies in your own texting style. It remembers every conversation, understands voice messages and never rushes things. You can take over any second.

This repository holds the builds only. The app updates itself from the latest release here.
